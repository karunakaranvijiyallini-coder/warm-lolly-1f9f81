Seatloom — assigned seating UI kit
An assigned-seat reservation component with keyboard navigation, blocked seats, party-size checks, final availability validation and reversible cancellation.

WHAT'S INSIDE
- index.html
- css/style.css: theme and responsive layouts
- js/main.js: fictional data and browser-local interactions
- css/vendor and js/vendor: Bootstrap 5.3.8

NOTES
Open index.html. No build step. JavaScript is required for application workflows. All records are fictional. Changes are saved only in this browser; storage restrictions fall back to the open tab. No backend, authentication, messages, payments or server-side bookings are included. Demo dates are fixed and labelled in the interface. Reset demo removes only this template's own local data.
